Open-ended questions about the mind, ethics, time, nature, society, the self, knowledge and creativity. There are no right answers; each one is an invitation to think.

All questions are original, written by Helix Velocities, and shared under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/) like all script content (see `LICENSES/README.md`).

To add a question, append an entry to `questions.json` with the next `bq-NN` id, one of the eight topics, and `source` set to `original question (<your name>)`. Keep it open-ended, ending with `?`, and at most 120 characters, and update the question count in `os/tests/test_big_questions.py`. See `CONTRIBUTING.md` for the full steps.
