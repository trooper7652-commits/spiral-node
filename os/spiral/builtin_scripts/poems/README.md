Short poems, all in the public domain: each was published before 1931 and its poet died before 1956.

Texts come from English Wikisource (https://en.wikisource.org). Every entry in `poems.json` has a `source` link to its page. The last page of each poem carries the poet's name.

Rebuild with `python tools/packs/build_poems.py` (the poem list is `tools/packs/poems_list.json`).
