# Daily Puzzle

One puzzle a day (riddles, logic, patterns and word puzzles), the same for the whole day, chosen from `puzzles.json` by the date. Answering it keeps your daily streak going. After that, practice puzzles from the rest of the library count toward a practice score but not the streak.

Puzzles are original (Helix Velocities) or classic riddles told in our own words. Every puzzle and its answer page must fit the screen: `python -m pytest -q tests/test_daily_puzzle.py` (run from `os/`).
